BAPTO ADMIN PASSWORD RESET FIX

1) Replace these files in GitHub:
   admin.html
   admin.js
   admin.css
   reset-password.html
   reset-password.js
   vercel.json

2) Commit changes and wait for Vercel to redeploy.

3) In Supabase Dashboard go to Authentication -> URL Configuration.
   Set Site URL to your main website, for example:
   https://www.baptechnicalofficial.com

4) Add Redirect URL:
   https://www.baptechnicalofficial.com/reset-password

   If you also use the non-www version or Vercel URL, add those reset-password URLs too.

5) Go to /admin and click Forgot password?.
   The admin email is pre-filled as bapnationalcom@gmail.com.

6) Open the reset email, choose a new password, then sign in again.

If the reset email does not arrive, check Authentication -> Users and confirm that bapnationalcom@gmail.com exists and is confirmed.
