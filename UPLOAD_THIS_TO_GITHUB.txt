BAPTO - ALL ANNOUNCEMENTS TO FACEBOOK UPDATE

UPLOAD / REPLACE THESE IN YOUR GITHUB REPOSITORY:
1. master.html
2. master.js

Keep your existing api/facebook-post.js and vercel.json from the Facebook API fix.
The complete ZIP also contains them.

WHAT CHANGED
- Every newly published announcement automatically posts to the connected official Facebook Page.
- Draft announcements post automatically when they are later changed to Published.
- Existing published announcements that were never sent to Facebook show as Facebook: pending.
- Master Admin has a 'Post Pending Announcements to Facebook' button to send all pending announcements in the current list.
- Each published announcement has a Post to FB button, or Post Again if it was already posted.
- Facebook post ID and posted date are saved in Supabase to prevent accidental duplicate auto-posts.

SUPABASE
If you already ran EVENTS_FACEBOOK_UPDATE.sql, no additional SQL is normally required.
If the columns are missing, run FACEBOOK_ALL_ANNOUNCEMENTS.sql in Supabase SQL Editor.

VERCEL
Keep these Environment Variables configured:
FACEBOOK_PAGE_ID=61595557911974
FACEBOOK_PAGE_ACCESS_TOKEN=(your private Page Access Token)
SUPABASE_URL=(your project URL)
SUPABASE_ANON_KEY=(your anon/publishable key)

Never upload the Facebook Page Access Token to GitHub.
