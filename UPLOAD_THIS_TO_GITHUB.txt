BAPOFFICIALS - API ROUTE FIX

The uploaded bapofficials-main.zip did not contain an api folder. Vercel therefore had no /api/facebook-post route to deploy.

UPLOAD THESE ITEMS TO THE ROOT OF THE SAME GITHUB REPOSITORY THAT CONTAINS index.html:

1) api/health.js
2) api/facebook-post.js
3) vercel.json (replace the existing file)

Your GitHub repository must look like:

index.html
master.html
master.js
vercel.json
api/
  health.js
  facebook-post.js

IMPORTANT VERCEL SETTINGS:
- Framework Preset: Other
- Root Directory: leave blank / repository root (or select the exact folder that contains index.html AND api/)
- Build Command: blank
- Output Directory: blank
- Install Command: blank

Then redeploy Production.

TEST 1:
https://www.baptechnicalofficial.com/api/health
Expected: JSON with "ok": true.

TEST 2:
https://www.baptechnicalofficial.com/api/facebook-post
Expected in a browser GET request: 405 Method not allowed.
That proves the function exists.

If /api/health is still 404, open the Vercel deployment and check Deployment Summary -> Functions. You should see /api/health and /api/facebook-post. If they are absent, the Vercel Root Directory is pointing to a different folder than the one containing api/.
