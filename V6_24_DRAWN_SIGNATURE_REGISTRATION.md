# V6.24 — Drawn Signature for Registration

## Added
Members can now **draw their signature online** directly inside the registration / membership application form.

## Works on
- Mobile phones
- Tablets
- Desktop / laptop using mouse or trackpad

## Included updates
- Member application form now accepts either:
  - uploaded signature image, or
  - drawn online signature
- Master Create Profile also supports drawn signature capture
- Master Edit Member also supports drawn signature replacement
- Drawn signatures are converted to PNG and uploaded to the existing `member-assets` storage bucket

## SQL
No SQL changes required.
